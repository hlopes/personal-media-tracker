# Two-stage Image Identification: vision observe, text reason

Image Identification matches an uploaded image to a `MediaItem` in two stages. Stage 1 calls the dedicated vision model (`cardvault-500m + mmproj` llama-server, OpenAI-compatible at `localhost:9001/v1`) with a plain free-text prompt (transcribe visible text, describe the scene) because the 409M model reads poster text well but cannot follow `Return JSON only` (verified: `No Time to Die` poster read correctly yet answered in prose, `Skyfall` misread as `Skynet`). Stage 2 feeds that observation to the text model on `:9000` via the injected langchain4j `ChatModel`, which turns it into structured `{title, year, mediaType, confidence: high|low, description}` JSON. We chose observe-then-reason over single-shot vision-JSON because strict JSON parsing of prose always yields not-identified, and over a pure OCR-text pipeline because the vision description also carries non-textual cues (tuxedo, gun, `007` logo) the text model can reason over. TMDB search grounds the reasoned title best-effort afterwards to resolve a "View in catalog" link.

# Season-level watch replaces episode-level watch for TV Series

Per-episode tracking introduced in ADR 0005 gave full granularity but added UI and data-model complexity (episode_watches, per-episode rating, unaired guards per episode, derived progress counting episodes). For simplicity we pivot to season-level atomic watches: one SeasonWatch row per User×Season (nullable Rating 1–5, watchedAt), derived LibraryEntry Status counts seasons (excluding season_number 0 Specials, rejecting seasons containing any unaired episode or future airDate). Episodes remain as read-only Catalog cache (title, synopsis, still, airDate, runtime) with no watch state, shown on detail page but no controls. Watched list TV cards now enumerate which seasons were watched (S1 ✓ ★★★★☆ · S2 ✓ · S3 ○ Not watched) plus  x/y seasons watched count, instead of episode progress. Movies cards unchanged. This supersedes ADR 0005; alternatives of keeping episode watches or allowing partial-season progress were rejected for overhead and unclear UX.
